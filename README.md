# Jarvis

Desk de trading personnel, basé sur [Captain Trading · Desk](https://github.com/captaincryptotrading21/desk).

En ligne : https://hugodescamps74-arch.github.io/jarvis

- Toutes les données viennent d'API publiques (OKX, Binance, TradingView…), appelées depuis le navigateur.
- La clé API Claude de l'Analyste reste dans le navigateur de l'utilisateur : elle n'est jamais dans ce dépôt.
- Stratégies suivies (or ORB Londres, ZEC et ETH Stratégie A) : suivi seulement, aucun ordre n'est passé.

`index.html` est le fichier construit (un seul fichier autonome).
